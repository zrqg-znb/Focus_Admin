# 产品模块地图

Focus 的核心文档入口按“模块主线”组织，而不是先按前后端分栏。这样更适合先理解业务域，再继续下钻到实现、页面和接口。

<FocusModuleGrid />

## 如何使用这组文档

- 先看模块页：快速理解模块边界、典型流程与关键 API
- 再看平台能力：理解 RBAC、调度、日志、监控等底座如何支撑业务模块
- 最后看技术参考：进入 `/backend/*` 与 `/frontend/*` 阅读实现附录
