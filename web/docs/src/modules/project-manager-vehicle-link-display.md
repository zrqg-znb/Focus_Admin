# 项目配置车控文档链接展示优化

## 背景

项目配置列表中的“用电信息表链接”和“软硬件接口文档”已经支持按芯片配置多条记录。列表页如果直接展示数据库 JSON 内容，会影响项目经理和质量/交付同学快速浏览项目配置状态。

## 目标用户

- 项目经理：快速判断项目是否已维护车控文档链接。
- 质量/交付同学：查看某个项目的芯片配置名与外部文档 URL。

## 范围

- 页面：`web-ele` 的 `project-manager/project` 项目配置列表。
- API：复用现有项目列表接口，不新增或调整后端字段。
- 展示：列表单元格仅显示配置数量；点击后弹出明细 Dialog。

## 非范围

- 不新增筛选、搜索、导出定制。
- 不调整后端模型、schema、migration。
- 不做文件上传或内部文档托管。

## 验收标准

- 无配置时显示“未配置”，不展示空数组或 JSON。
- 多条配置时显示“已配置 N 条”。
- 点击数量后弹出 Dialog，展示芯片配置名和 URL。
- URL 以新标签页打开，并按外链处理；缺少协议时补 `https://`。
- 兼容旧字符串值，按 1 条配置展示。
