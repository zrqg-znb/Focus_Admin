# 需求中心后端实现附录

需求中心后端位于 `backend-django/apps/requirement_center/`，围绕需求主对象、状态流转、统计聚合和工作区快照展开。

## 核心子域

当前需求中心主要由以下子域组成：

- `requirement/`
  需求主模型、列表、详情、状态流转
- 需求工作区快照
  为工作台和聚合面板提供摘要视图

## 核心模型

主要模型位于：

- `requirement/requirement_model.py`

核心对象通常包括：

- 需求主对象
- 需求状态与分类
- 需求归属项目 / 迭代 / 责任人等上下文

## 核心服务职责

主要服务位于：

- `requirement/requirement_services.py`

负责：

- 需求列表与分页筛选
- 需求详情读取
- 状态更新与批量处理
- 统计口径计算
- 工作区聚合快照生成

## 实现重点

- 工作台里看到的需求摘要不是单独页面硬编码，而是后端聚合服务提供
- 需求状态流转通常会影响项目、迭代和工作区统计
