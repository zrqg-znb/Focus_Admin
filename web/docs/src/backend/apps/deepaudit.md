# DeepAudit (智能审计)

DeepAudit (`deepaudit`) 模块是系统的核心智能化应用之一，旨在利用大语言模型 (LLM) 和检索增强生成 (RAG) 技术，为项目提供自动化的代码漏洞审计、安全分析与修复建议。

## 架构概览

### 核心架构设计

DeepAudit 采用微服务架构思想构建，内聚了多个关键子系统：

```
┌─────────────────────────────────────────────────────────────┐
│                       DeepAudit (深度审计)                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌───────────────┐ ┌───────────────┐ ┌─────────────────┐   │
│   │  Agent Engine │ │  LLM Adapter  │ │ RAG & Knowledge │   │
│   │ (多智能体编排) │ │ (模型抽象层)   │ │ (检索增强知识库) │   │
│   └───────────────┘ └───────────────┘ └─────────────────┘   │
│           │                 │                  │            │
│   ┌───────┴─────────┬───────┴─────────┬────────┴────────┐   │
│   ▼                 ▼                 ▼                 ▼   │
│ ┌────────┐      ┌────────┐        ┌────────┐       ┌────────┐
│ │Project │      │TaskMgr │        │  Rule  │       │DashBrd │
│ │ 项目管理│      │任务编排 │        │ 审计规则│       │ 数据看板│
│ └────────┘      └────────┘        └────────┘       └────────┘
└─────────────────────────────────────────────────────────────┘
```

### 关键组件

- **Agent Engine (多智能体编排)**：提供基于图的控制器 (`graph_controller`) 和编排器 (`orchestrator`)，通过多个特化智能体（如分析、验证、信息收集）协作完成复杂的代码审计任务。
- **LLM Adapter (大模型抽象层)**：通过 `base_adapter` 和 `factory` 设计模式，兼容接入多种大语言模型（如百度、字节豆包、Minimax、LiteLLM），并实现了提示词缓存与记忆压缩。
- **RAG & Knowledge (检索增强知识库)**：包括文档的切割、向量化 (`embeddings.py`) 与索引，以及针对特定漏洞（如 SQL 注入、XSS、业务逻辑漏洞）和框架（Django, FastAPI, React）的结构化知识库加载。
- **任务管理 (Task Management)**：包括 `scan_task` 和 `agent_task`，通过 Celery 和 WebSocket 处理长耗时的代码扫描，并将分析过程实时流式推送到前端。
- **审计规则与提示词 (Audit Rule & Prompt Template)**：支持用户自定义的审计规则与 LLM 提示词模板，灵活适应不同项目的扫描需求。

## 核心功能

1. **智能漏洞扫描**：深度解析项目代码结构，利用 LLM 结合代码扫描工具进行上下文感知的漏洞发掘。
2. **多智能体协作**：任务在多个专业智能体之间流转，确保误报率的降低并提供可操作的修复建议。
3. **实时流式反馈**：通过 `streaming/stream_handler` 将大模型的推理过程和任务进度通过 WebSocket 实时反馈给前端用户。
4. **自定义扫描画像 (Scan Profile)**：允许为不同项目配置不同的扫描策略、使用的模型及关注的漏洞类别。

## API 接口与通信

- **RESTful API**：
  - `/api/deepaudit/project`：审计项目与 Git 仓库绑定管理。
  - `/api/deepaudit/scan_task`：扫描任务的创建、状态查询与结果拉取。
  - `/api/deepaudit/audit_rule`：审计规则的管理。
  - `/api/deepaudit/rag`：知识库和向量索引操作。
- **WebSocket**：
  - 用于推送 `agent_task` 的实时进度、LLM 流式输出与警告通知。

## 使用场景

- 研发团队在代码提交或合并请求前，通过 DeepAudit 发起自动化安全检查。
- 安全团队自定义针对公司特定框架的漏洞特征知识库，提升扫描的准确度。
- 管理层通过 Dashboard 查看全项目的安全水位和漏洞分布趋势。
