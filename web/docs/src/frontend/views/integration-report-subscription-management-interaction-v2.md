# 集成报告 - 订阅管理前端交互逻辑说明文档

## 1. 批量管理场景交互逻辑

### 1.1 多维度项目筛选
- **功能描述**：管理员可以在项目列表上方通过多维度条件筛选项目。
- **筛选条件**：
  - 关键字搜索（配置名/项目名）
  - 项目类型（自研项目、外包项目、生态项目）
  - 配置状态（启用、停用）
  - 订阅情况（已有订阅人、暂无订阅人）
  - 邮箱风险（存在无邮箱订阅人、无邮箱缺失）
  - 创建时间（日期范围筛选）
- **交互效果**：选择或输入条件后，表格自动触发查询请求更新项目列表数据。

### 1.2 批量操作二次确认与进度反馈
- **操作路径**：勾选一个或多个项目 -> 点击“批量订阅选定项目” -> 弹出用户选择框 -> 确认选择 -> 二次确认弹窗 -> 进度反馈。
- **二次确认**：点击确认选定用户后，弹出 `ElMessageBox.confirm` 提示“确认将选中的 X 个用户批量追加订阅到 Y 个项目中吗？”，要求管理员确认，避免误操作。
- **进度展示**：点击确认后，右上角会弹出 `ElNotification` 实时展示操作进度：“正在处理 X 个用户的订阅请求，请稍候...”。
- **结果反馈**：接口调用成功后，通知变为成功状态，并显示实际变更的订阅关系数量；同时自动清空勾选项并刷新项目表格数据。若发生网络错误或接口异常，会关闭加载通知并弹出错误提示。

## 2. 大量用户新增场景交互逻辑

### 2.1 从组织架构树批量选人
- **操作路径**：项目详情抽屉 -> 点击“从组织架构选人” -> 弹出带组织架构树的用户选择器。
- **交互逻辑**：
  - 左侧展示组织架构树，支持通过部门名称模糊搜索。
  - 选中部门后，右侧展示该部门下的用户列表，支持跨部门多选。
  - 选定并点击“确认”后，系统在前端执行**去重校验**（比对已存在的订阅用户 `user_id`），若所选用户已全部存在则拦截并提示“所选用户均已在订阅列表中”。
  - 校验通过后，自动调用追加订阅接口，并触发局部刷新，右上角提示“追加完成，成功新增 X 人（已自动去重）”。

### 2.2 批量导入订阅人（Excel）
- **操作路径**：项目详情抽屉 -> 点击“批量导入” -> 弹出导入对话框。
- **交互逻辑**：
  - **模板下载**：点击右上角“下载模板 Excel”，前端通过 `xlsx` 库动态生成并下载标准的导入模板（包含：用户名、姓名、邮箱等列）。
  - **文件上传解析**：拖拽或点击上传 `.xlsx` 或 `.csv` 文件。系统通过前端解析 Excel 内容，提取“用户名”或“邮箱”列作为匹配关键字。
  - **空文件与非法格式拦截**：若文件为空或未包含有效用户标识，前端直接抛出错误提示。
  - **进度条展示**：解析过程中，界面会切换为进度条视图，实时更新“解析文件”、“校验匹配用户”、“追加订阅人”的阶段性文本和百分比（10% -> 30% -> 80% -> 100%）。
  - **后端匹配与去重**：前端逐一或批量调用 `searchUserApi` 查询有效用户的 `user_id`，并与当前列表数据去重。对未匹配到的用户进行记录，在导入完成后通过 `ElMessage.warning` 告知管理员部分用户未找到。

### 2.3 已添加用户列表与移除优化
- **展示优化**：已添加用户列表中新增“操作”列。
- **单条移除**：点击“移除”按钮，触发气泡确认框（`ElPopconfirm`），确认后调用移除接口并刷新列表，相比原来必须勾选再点击上方移除的流程更加直接高效。
- **批量移除**：保留了顶部的“移除选中”功能，适用于批量清理订阅人的场景。

## 3. 异常处理与兼容性
- **按钮防抖与防重**：所有的提交、保存、导入操作按钮均绑定了 `loading` 状态，防止用户在接口响应前重复点击。
- **降级提示**：由于部门人员数据可能庞大，Excel 导入过程如遇到未识别的用户，不会直接阻断正常用户的导入，而是采用“尽力而为”的策略，导入成功后统一汇总报错信息。
- **响应式布局**：抽屉内部的 Toolbar 与信息汇总区域已适配小屏幕展示，保证移动端或窄屏场景下的可用性。
