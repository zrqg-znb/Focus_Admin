# 自动化测试报告页面

自动化测试报告 (`auto-test-report`) 模块前端页面用于展示和管理自动化测试执行的统计数据、具体用例日志以及测试车辆配置。

## 页面结构

该模块包含以下三个核心视图：

### 1. 日常测试结果 (Daily Results)
位于 `views/auto-test-report/daily-results/`：
- **功能**：展示每日的自动化测试汇总数据，包括总用例数、通过数、失败数及通过率等。
- **交互**：支持通过日期范围或特性标签进行筛选，帮助团队快速定位某个构建版本的测试质量。

### 2. 测试用例追踪 (Test Cases)
位于 `views/auto-test-report/test-cases/`：
- **功能**：列出每次测试的详细用例记录，包括执行状态、失败原因和绑定的 DTS 问题单。
- **组件**：
  - `TestCaseHistoryDrawer.vue`：点击某条失败用例时弹出的抽屉，展示完整的执行日志、控制台输出和错误截图等详细信息。
- **交互**：支持用例名称搜索、状态过滤以及 DTS 单号关联。

### 3. 车辆/设备配置 (Vehicle Config)
位于 `views/auto-test-report/vehicle-config/`：
- **功能**：维护自动化测试所依赖的硬件载体或车辆的具体软硬件版本配置。
- **交互**：支持配置项的增删改查，并记录每次修改的版本历史，确保测试环境的可追溯性。

## 数据流转与接口

- 页面通过 `@/api/auto-test-report/index.ts` 封装的 Axios 接口与后端交互。
- 采用 Vben Admin 的 `useVxeTable` 组合式函数实现复杂数据表格的高效渲染与本地/远端过滤。
