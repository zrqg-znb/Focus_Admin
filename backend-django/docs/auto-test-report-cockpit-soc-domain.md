# Auto Test Report 座舱 SOC 领域

## 概要

自动化测试模块在原有“座舱、车控”基础上新增“座舱 SOC”领域，并将原“座舱”展示文案调整为“座舱 MCU”。

## 领域编码

- `cockpit`: 座舱 MCU
- `cockpit_soc`: 座舱 SOC
- `vehicle`: 车控

为兼容历史数据和下游 CI，原有 `cockpit` 编码保持不变，只调整前端与后台展示文案。

## 座舱 SOC 规则

- SOC 版本、车型、用例配置结构整体复用座舱 MCU。
- SOC 用例新增 `module` 字段，创建、编辑、Excel 导入时必填。
- `module` 仅作为用例属性、展示字段和导入导出字段，不参与每日结果上报匹配。
- 每日结果上报接口保持不变，仍按 `vehicle_code + case_no` 匹配用例。

## 导入导出

- 座舱 MCU 模板：`用例编号 / 用例名称 / 备注`
- 座舱 SOC 模板：`模块 / 用例编号 / 用例名称 / 备注`
- 车控模板：`VIU编号 / 用例编号 / 用例名称 / 备注`

## 看板与下游任务

- 座舱 SOC 每日结果明细和历史会展示 `module`。
- 车控仍展示 `VIU编号`。
- 座舱 MCU 下游 CI 触发能力仍只作用于 `cockpit`，即座舱 MCU；座舱 SOC 不参与该门禁和触发链路。
