# Auto Test Report 未执行统计口径

## 背景

测试用例执行看板必须暴露漏执行风险。车型已经注册且启用的用例，如果某个执行日期没有上传最新执行结果，不能从总用例数中消失，否则会让漏执行问题被误判为正常。

## 统计规则

- 总用例数：当前车型下启用且未删除的注册用例数。
- 成功、失败、超时、跳过：只统计当日已上传结果中的最新记录。
- 未执行：启用注册用例数减去当日有最新结果的用例数。
- 异常车型：存在未执行、失败、超时或跳过时均判定为异常。

## 展示规则

- 全量概览展示独立的“未执行”列，对应接口字段 `missing_result_count`。
- 单车型明细会为未上传结果的注册用例生成只读 `missing/未执行` 行。
- 未执行行不落库、不进入历史记录、不允许填写异常原因或根因大类。
