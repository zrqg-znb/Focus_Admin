# 沟通矩阵 Markdown 导出说明

## 背景

沟通矩阵导出的 Markdown 文件用于快速查找领域、节点、岗位和人员关系。文件更关注内容检索和排版稳定性，不承载导出时间、统计数量等运行信息。

## 导出结构

- 文件标题固定为 `# 沟通矩阵`。
- 每个一级节点作为一个领域章节，格式为 `## 领域名称`。
- 每个领域章节下输出一个 HTML table，用 HTML 表格支持 `rowspan` 合并单元格。
- 表格列固定为：二级节点、三级节点、岗位、人员、描述。
- 不导出层级、节点编码、关联项目、层级路径、导出时间、节点数量、岗位数量、人员数量。

## 合并与展示规则

- 一级节点只作为章节标题，不进入表格行。
- 二级节点单元格按其下所有岗位行数合并。
- 三级节点单元格按该三级节点下所有岗位行数合并。
- 二级节点自身存在岗位时，作为“三级节点为空”的岗位行展示。
- 三级节点没有岗位时保留一行，岗位和人员显示 `-`，避免空节点在导出中消失。
- 四级及更深节点合并到三级节点名称中，用 ` / ` 拼接路径。
- 岗位名称和人员姓名使用 `<strong>` 加粗，多个人员用 `、` 分隔。
- 富文本描述会转为纯文本并做 HTML 转义，避免破坏表格结构。
