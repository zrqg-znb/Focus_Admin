# 静态扫描结果明细导出

## 背景

静态扫描项目结果详情页需要支持导出最新扫描明细，便于线下分析和归档。导出入口位于项目结果详情页右上角。

## 导出范围

- 导出当前项目的最新成功扫描结果。
- 每个扫描工具生成一个 Excel sheet。
- 导出不受页面分页影响，会导出筛选后的全部明细。
- 导出会沿用页面的子模块、关键词和状态筛选。
- 无论页面状态筛选如何，`Shielded` 已屏蔽记录都不会写入 Excel。

## 字段策略

Excel 每行表示一条扫描结果明细，保留业务排查所需字段：

- 工具、子模块、文件路径、行号。
- 缺陷类型、严重程度、缺陷描述、屏蔽状态。
- 修复建议、代码片段。

结果 ID、任务 ID、缺陷指纹、命中/身份/任务追踪类字段不导出，避免 Excel 中出现内部治理字段。
